## 🚀 Featured Projects

### 🔎 SubTerra
Pure Python **subdomain enumeration and reconnaissance tool** designed to expand an organization's external attack surface.

- Aggregates subdomains from **17+ passive sources**
- Uses **Certificate Transparency logs**, OSINT datasets, and bug-bounty archives
- Supports parallel processing
- Performs real-time deduplication
- Built entirely with Python standard-library capabilities

### 🦈 SubShark
Pure Python **subdomain takeover vulnerability scanner** for identifying potentially hijackable subdomains.

- Probes targets over **HTTP/HTTPS**
- Fingerprint-matches response bodies against known service signatures
- Detects potentially vulnerable **subdomain takeover** conditions
- Supports concurrent scanning
- Crash-safe resume capability
- JSON output for structured results
